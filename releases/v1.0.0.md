The first desktop release of UnoPlay brings the classic-skinned player to Windows x64, Linux x64, and Apple Silicon Macs. You can also [play UnoPlay in the browser](https://wieslawsoltes.github.io/UnoPlay/).

- Load Winamp Classic `.wsz` skins or use the bundled Midnight skin. The player includes dockable main, equalizer, playlist, video, media library, and MiniBrowser windows.
- Play local music, MP4 video, and HTTP streams. Available codecs and streaming features depend on the platform media backend.
- Adjust the ten-band EQ, import Winamp presets, and switch between spectrum and waveform displays.

The archives include the .NET runtime. Linux uses X11 or XWayland. On Ubuntu, install `libvlc-dev vlc-plugin-base vlc-plugin-video-output` for native video and network playback. The optional Linux MiniBrowser uses GTK 3 and WebKitGTK 4.1.

To verify your download, compare its SHA-256 digest with the matching entry in [SHA256SUMS](https://github.com/wieslawsoltes/UnoPlay/releases/download/v1.0.0/SHA256SUMS).
